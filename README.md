### About Me

I’m a **Computer Engineer** and **Cybersecurity Master’s student** bridging applied AI security with production fullstack engineering. My academic work centers on adapting Large Language Models for automated vulnerability remediation, while my engineering work spans resilient web platforms, messaging automation, and embedded edge diagnostics. I care about clean architecture, deterministic systems, and code that holds up under real-world constraints.

- 🛡️ **Research Focus:** Fine-tuning LLMs (QLoRA + RAG) for stack-specific security recommendations and SBOM vulnerability triage.
- ⚙️ **Engineering:** Building fullstack TypeScript/Node.js applications, edge hardware telemetry pipelines, and automated workflows.
- 🎯 **Philosophy:** Security shouldn't be an afterthought—and neither should maintainability.
